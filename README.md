# OpenGym Tokyo

**そのジムのマシンを知っている、AIトレーナー。**
都知事杯オープンデータ・ハッカソン 2026 提出作品 — https://opengym-tokyo.pages.dev

---

## 課題

民間ジム（ちょこザップ等）には専用アプリがある。施設の詳細、マシンの使い方、
トレーニング記録、食事記録、個別のアドバイス。ぜんぶ入っている。

**都内75施設の公営ジムには、無い。**

汎用の食事記録アプリはあるし、トレーニング解説はYouTubeに山ほどある。
でも **「そのジムに実際にあるマシン」を踏まえた記録とアドバイス** だけは、どこにも無い。

理由は単純で、マシン構成は施設ごとに違い、どこにも記録されていないから。
自治体標準オープンデータセット「スポーツ施設一覧」は198カラム定義されているが、
マシン構成は **列そのものが存在しない（0/75施設）**。

## 考え方

**オープンデータを整えることが目的ではない。** 使いやすいアプリを作るために必要な
データが無い、という順序で考える。ではその足りないデータを、誰に負担をかけずに作るか。

一極集中で誰かが手間をかけて作るのでは続かない。**使う人が少しずつ整える。**

```
① 自分のために      マシン名と重量を入力する（記録したいから、入力する）
        ↓
② 同意した分だけ    施設の共有データへ（重量・日付は共有しない）
        ↓
③ 次に来た人は      設定作業ゼロ。もう並んでいる
        ↓
④ その人も          1台だけ足す。負担はひとかけら
        └──────────→ 使う人が増えるほど、勝手に整っていく
```

整備のためのボランティアは要らない。**入力する理由が、自分にある。**

## 機能

- **記録は3タップ。** そのジムに実際にあるマシンだけが並び、重量は実機の刻み幅どおり
- **AIトレーナー。** 設置マシンと記録履歴だけを根拠に、実在する重量で次回を提案する
- **マシンを足す。** 自由入力。同意すればその施設の共有データになる
- **みんなが整えたデータ。** 延べ何人の入力から何台登録されたかが見え、取り込める
- **AIで一括登録。** 「ラットプルは10から80まで5キロ刻み」と書けばJSONになる（運営者向け）
- **オフラインで動く。** 記録は端末内。地下ジムでも使える

## 構成

```
index.html              単一ファイルのフロントエンド
data.js                 ビルド済みデータ（オフライン動作のため同梱）
functions/api/parse.js  自然文 → 施設設定JSON（Workers AI）
functions/api/coach.js  AIトレーナー（Workers AI）
functions/api/share.js  施設データの共有ストア（Workers KV）
scripts/build_data.py   オープンデータ取得・集計
scripts/geocode.py      住所からの緯度経度補完（国土地理院）
```

参加者特典の **Cloudflare Pages / Workers AI / Workers KV** をそのまま利用している。
AIモデルは特典マニュアル推奨の **Qwen3 30B FP8**。

## データ

| | |
|---|---|
| 対象 | 都内 **55自治体 / 890施設**、うちトレーニング室あり **75施設** |
| 地図に置ける | **100%**（オープンデータ側は42.7%。残りは住所から補完） |
| マシン構成 | **0%** — 列が存在しないため、利用者の入力で育てる |

再生成：

```bash
python3 scripts/build_data.py && python3 scripts/geocode.py
```

## 利用オープンデータ

- **自治体標準オープンデータセット「スポーツ施設一覧」** — 東京都オープンデータカタログサイト／都内57自治体が公開／**CC BY 4.0**
- **国土地理院 地名検索API** — 住所からの緯度経度補完

出典：東京都オープンデータカタログサイト（各区市町村提供）

## プライバシー

トレーニング記録（重量・日付）は端末内にのみ保存し、共有しない。
共有されるのは、明示的に同意されたマシン構成（名称・重量レンジ・刻み幅）だけ。

## 前身

[gymnery](https://github.com/ambit1977/gymnery)（個人用のトレーニング記録PWA）を、
公営ジム向け・マルチ自治体展開の観点で作り直したもの。
