# OpenGym Tokyo

**公営ジムの記録と、施設データを育てる仕組み。**
都知事杯オープンデータ・ハッカソン 2026 提出作品

---

## 何をするものか

東京都内の公営ジムは **55自治体・75施設** ある。安くて近くて誰でも使える。
ところが「どこにあるか」「何時から開いているか」を機械で調べられない。

自治体標準オープンデータセット「スポーツ施設一覧」は **198カラム** 定義されているのに、
実際に埋まっているのは——

| 項目 | 充足率 |
|---|---:|
| 緯度・経度 | **30.1%** |
| 車椅子可 | 25.8% |
| フリーWi-Fi | 29.0% |
| 更衣室 | 39.9% |
| 開館時間 | 57.4% |
| 所在地 | 100% |

*55自治体・890施設の公開CSVを全カラム検査した実測値（`scripts/build_data.py`）*

**器はある。中身が無い。** そしてマシン構成にいたっては、列そのものが存在しない。

OpenGym Tokyo は、その空白を **生成AIと利用者・運営者** で埋める。

```
標準オープンデータ  →  ① AIが基礎JSONを生成  →  ② 利用者が話しかけて追記  →  ③ アプリが動く
   CC BY・57自治体          公開情報を辿って下書き        専用プロンプト → JSON        施設設定JSONを読む
                                                                    ↑                        │
                                                                    └──── 使うほど育つ ───────┘
```

## 特徴

- **JSONを書かせない。** 「ラットプルは10から80まで5キロ刻み」と話しかければ構造化される。受付の人でも編集者になれる
- **フレームワーク本体と施設設定JSONを分離。** 57自治体が同一スキーマなので、設定を差し替えれば隣の区でも動く
- **オフラインで動く。** 電波の悪い地下ジム対策。記録は端末内（localStorage）

## 構成

```
index.html            単一ファイルのフロントエンド
data.js               ビルド済みデータ（オフライン動作のため同梱）
data/coverage.json    充足率の実測
data/facilities.json  トレーニング室のある75施設
scripts/build_data.py オープンデータ取得・集計
```

## データを再生成する

```bash
python3 scripts/build_data.py
```

東京都オープンデータカタログサイトのCKAN APIから、データセットコード `d3100000004`
（自治体標準オープンデータセット「スポーツ施設一覧」）を全自治体分取得して集計する。
